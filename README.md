## Engineering in public

### [fplbench](https://github.com/PascalAI2024/fplbench) · Data engineering & applied ML

A leakage-aware Fantasy Premier League dataset and forecasting benchmark. Predictions are frozen before the deadline and scored against verified results. Python and LightGBM, with a public evaluation record.

[Dataset](https://huggingface.co/datasets/x0me/fplbench) · [Live board](https://huggingface.co/spaces/x0me/fplbench-board)

### [Maple CUDA](https://github.com/PascalAI2024/maple-preview-windows-cuda) · GPU optimization

Original CUDA optimization patches and benchmark tooling built on Maple/llama.cpp. Published experiments record generation from **52 to 377 tok/s** and prompt processing from **1,457 to 10,674 tok/s**, with **103 CPU-reference cases**. These are hardware- and revision-specific results from separately documented experimental runs.

[Case study](https://github.com/PascalAI2024/portfolio/blob/main/case-studies/maple-cuda.md) · [Benchmark records](https://huggingface.co/datasets/x0me/maple-preview-cuda-benchmarks)

### [ZiggyZag](https://github.com/PascalAI2024/ZiggyZag) · Native developer tools

An all-Zig shell workspace with native terminal hosts, a cross-platform launcher and a local AI sidecar. Active alpha, with tests and [published prereleases](https://github.com/PascalAI2024/ZiggyZag/releases).

### [JarvisNano](https://github.com/PascalAI2024/JarvisNano) · Embedded firmware

C/ESP-IDF firmware for an ESP32-S3 desk companion: touch display, live voice and device interaction. A tested hardware release candidate with remaining hardware verification gates.

Other public work: [Qwen Quant Bench](https://github.com/PascalAI2024/qwen38-27b-quant-bench), a completed quantization research record; [Verrow](https://github.com/PascalAI2024/verrow), a partial data-quality workbench prototype; [PicoArmy](https://github.com/PascalAI2024/picoarmy), an agent-management prototype built around the upstream picobot runtime; and [KinTunnel](https://github.com/PascalAI2024/kintunnel), a tested dry-run networking MVP.
